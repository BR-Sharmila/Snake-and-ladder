# 🐍 Snake & Ladder Game

A simple two-player graphical Snake & Ladder game developed using Python and Tkinter.

## 🎮 Features

- 🎲 Two-player dice game
- 🔴 Player 1
- 🔵 Player 2
- 🐍 Snakes
- 🪜 Ladders
- 📊 Live player positions
- 🏆 Winner detection
- 🔄 Restart button
- 🎨 Graphical 10 × 10 game board

## 🛠️ Technologies Used

- Python 3.13
- Tkinter
- Random
- Math
