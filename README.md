# 🐍 Snake & Ladder Game 🪜

A simple and interactive **Snake & Ladder game** developed using **Python and Tkinter**.

This is a two-player desktop game where players roll the dice, move across a 10 × 10 board, climb ladders, slide down snakes, and compete to reach position 100 first.

---

## 🎮 Features

- 🎲 Two-player dice game
- 🔴 Player 1
- 🔵 Player 2
- 🐍 Snakes
- 🪜 Ladders
- 🎯 Automatic player movement
- 🎲 Animated dice rolling
- 📊 Live player positions
- 🏆 Winner detection
- 🔄 Restart button
- 🎨 Graphical 10 × 10 game board
- ⚡ Simple and easy-to-use interface

---

## 🛠️ Technologies Used

- 🐍 Python 3.13
- 🖥️ Tkinter
- 🎲 Random module
- 📐 Math module

---

## 🎯 How to Play

1. Start the game.
2. Player 1 rolls the dice.
3. The player moves according to the dice number.
4. If the player lands on a ladder, they climb up.
5. If the player lands on a snake, they move down.
6. Players take turns.
7. The first player to reach **100** wins the game. 🏆
