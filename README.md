### 🐍 1. Snake & Ladder

A two-player graphical Snake & Ladder game developed using Python and Tkinter.

- 🎲 Two-player gameplay
- 🐍 Snakes
- 🪜 Ladders
- 🎲 Animated dice
- 🏆 Winner detection
- 🔄 Restart button
- 🎨 10 × 10 graphical board

**Technology:**
- Python 3.13
- Tkinter
- Random
- Math

```bash
