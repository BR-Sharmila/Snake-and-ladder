# 🐍 Snake & Ladder Game

A simple graphical Snake & Ladder game developed using Python and Tkinter.

## Features

- 🎲 Two-player dice game
- 🔴 Player 1
- 🔵 Player 2
- 🐍 Snakes
- 🪜 Ladders
- 📊 Live score
- 🏆 Winner detection
- 🔄 Restart button
- 🎨 Graphical game board

## Technologies Used

- Python 3.13
- Tkinter
- Random
- Math

## How to Run

Install Python 3.13 and run:

```bash
py -3.13 gui_game.py
